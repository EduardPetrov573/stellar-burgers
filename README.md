# Stellar Burgers

Приложение космической бургерной на React и TypeScript, созданное на основе стартового набора. Состояние приложения хранится в Redux Toolkit, навигация построена на React Router.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```sh
npm ci
cp .env.example .env
npm start
```

Приложение откроется по адресу http://localhost:4000. В корневом `.env` должна быть строка:

```dotenv
BURGER_API_URL=https://norma.ffapi.ru/api
```

Локальный `.env` исключён из Git. Рабочий адрес API также указан в `.env.example`.

## Возможности

- Конструктор: выбор и замена булки, добавление, удаление и перестановка начинок, счётчики и итоговая стоимость.
- Информация об ингредиенте и заказе открывается в модальном окне при переходе из списка и на отдельной странице по прямой ссылке.
- Публичная лента заказов с ручным обновлением, статистикой и автоматическим обновлением каждые 5 секунд.
- Регистрация, вход, восстановление пароля и выход. Истёкший access token обновляется через refresh token.
- Защищённые профиль и история заказов. После входа восстанавливается запрошенный маршрут.
- Профиль позволяет сохранить только изменённые поля или отменить редактирование. История заказов автоматически обновляет статусы каждые 5 секунд; после оформления заказа оба списка запрашиваются сразу.
- Оформление заказа доступно авторизованным пользователям. После успешного запроса показывается номер заказа и очищается конструктор.
- Мобильная навигация и адаптивное отображение карточек.

## Маршруты

| Адрес                                 | Страница              | Доступ        |
| ------------------------------------- | --------------------- | ------------- |
| `/`                                   | Конструктор           | Всем          |
| `/ingredients/:id`                    | Ингредиент            | Всем          |
| `/feed`                               | Лента заказов         | Всем          |
| `/feed/:number`                       | Заказ                 | Всем          |
| `/login`, `/register`                 | Вход, регистрация     | Гостям        |
| `/forgot-password`, `/reset-password` | Восстановление пароля | Гостям        |
| `/profile`                            | Профиль               | Пользователям |
| `/profile/orders`                     | История заказов       | Пользователям |
| `/profile/orders/:number`             | Заказ из истории      | Пользователям |
| `*`                                   | Страница 404          | Всем          |

## Проверки

```sh
npm run typecheck
npm run check
npm run build
npm test -- --runInBand
npx playwright install chromium
npm run e2e
```

Браузерные тесты используют тестовые ответы HTTP API: проверяют сборку и оформление бургера, авторизацию, возврат на защищённый маршрут, профиль, восстановление пароля, модальные окна, обновления заказов и мобильное меню. Jest проверяет ошибки запросов, повторное оформление заказа, очистку приватных данных при выходе и совместное обновление токена параллельными запросами.

Если Chromium уже установлен в системе, его путь можно передать через переменную `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

## Структура

- `src/services` — слайсы ингредиентов, конструктора, пользователя, заказов и ленты, селекторы, типизированные хуки и thunk для автоматического обновления заказов. Redux DevTools включён в режиме разработки.
- `src/utils/burger-api.ts` — методы HTTP API и обновление токена.
- `src/pages` — страницы, связанные с состоянием приложения.
- `src/components/ui` — переиспользуемые компоненты стартового набора.

Сборка находится в `dist`. При размещении на сервере для прямых ссылок нужно возвращать `index.html` для маршрутов приложения.
